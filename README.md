# Footly

A lightweight Chrome extension for football fans: upcoming matches, live scores,
and results in a compact popup, prioritizing your favorite teams and
competitions, with optional match alerts.

- Manifest V3; no account, no tracking, no host permissions.
- Data from ESPN's public football endpoints.
- Privacy policy: [PRIVACY.md](PRIVACY.md)

## Development

Requires Node.js and npm.

```bash
npm install
npm run dev      # Vite dev server
npm test         # Vitest, single run
npm run lint
```

To try it in Chrome:

1. Run `npm run build`.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select `dist/`.

## Release

```bash
npm run package  # builds, then zips dist/ to release/footly-<version>.zip
```

`STORE_LISTING.md` holds the Chrome Web Store text, the permission
justifications, the screenshot guide, and the submission checklist.

The extension icon is generated by `node scripts/generate-icons.mjs`.
